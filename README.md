# 合成大西瓜

## 体验地址

https://game.hullqin.cn/dxg

## 本地游玩

在项目根目录运行以下命令，从终端显示的地址打开游戏列表。

```powershell
npm.cmd ci --ignore-scripts --no-audit --no-fund
npm.cmd run dev -- --host 127.0.0.1
```

H 区包含「合成大西瓜」和「合成大西瓜 · 果园版」。果园版可在电脑浏览器中通过 `/watermelon-orchard/` 直接进入，支持鼠标和键盘投放。
