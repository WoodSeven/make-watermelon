# 小游戏站界面风格参考

参考图为用户提供的微信服务入口截图（2474 × 1174 像素）。顶部绿弧提供整页的视觉识别，浅灰背景和规则网格组织内容。白色卡片以彩色图标和简短名称标识入口，方便用户快速扫视。

## 布局与层级

- **顶部色块**铺满宽度，下边缘是一条平缓的弧线，画面中央约下探 142 像素。第一排卡片约从纵坐标 226 像素处开始，弧线与网格之间有明显留白。
- **卡片网格**在桌面截图中呈四列。网格整体居中，宽约 1194 像素，卡片约为 271 × 229 像素，横纵间距约 37 像素。同样的尺寸和对齐让各入口保持相近的视觉权重。
- **单张卡片**用小圆角和白色底面与页面背景分层。彩色图标约宽 40 像素，居中置于深色中文标题上方。同一排卡片的图标和标题分别对齐，标题使用无衬线字形。
- **可见状态**是“小程序”卡片周围约 2 像素的深色描边。静态截图无法确认描边由哪种交互触发。

| 页面背景 | `#F7F7F7` |

| 标题文字 | `#191919` |

绿色集中在页首，彩色图标集中在入口，页面大部分面积由浅灰和白色构成。深色文字提供稳定的阅读对比，标题和图标一起表达入口含义。

## 在小游戏站中的应用

- 游戏列表采用居中的卡片网格，统一卡片尺寸、圆角和间距。每张卡保留清楚的游戏名称和原创图标，整张卡作为入口。
- 用本站的色板、弧线比例和图标建立视觉识别。把饱和色集中用于页首装饰和游戏图标，卡片和背景维持低对比度，入口标题保持清晰。
- 窄屏时按可用宽度减少列数，保留可读标题、卡片间距和完整的触控区域。键盘焦点使用清晰的描边，状态切换时保持卡片位置稳定。
